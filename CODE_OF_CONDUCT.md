# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be respectful and welcoming. Assume good intent.
- Give and accept constructive feedback gracefully.
- No harassment, insults, personal or political attacks, sexualized language or imagery, or publishing others' private information.

## Scope

This code applies in all project spaces, including issues, pull requests and discussions, and when someone represents the project in public.

## Reporting

To report unacceptable behavior, contact the maintainers privately through [GitHub's private vulnerability reporting](https://github.com/aieo-product/claude_qamods/security/advisories/new) (choose it even for conduct reports, and say so in the title). Reports are reviewed promptly and kept confidential.

Maintainers may remove, edit or reject contributions that do not follow this code, and may temporarily or permanently ban contributors for behavior they deem harmful, following the enforcement guidelines of the Contributor Covenant.
